# الأمان والخصوصية

## حدود الثقة

```
 ┌──────────── جهاز المستخدم ─────────────┐        ┌──────── الخادم ────────┐
 │ متصفح (صفحة التطبيق، أصل موثوق)        │ HTTPS  │ Laravel + الحزمة        │
 │   │  HTTP loopback + Origin + Bearer   │◀──────▶│ مصادقة، CSRF، تحقق،     │
 │   ▼                                    │        │ تخزين خاص، صلاحيات      │
 │ Scanner Agent (صلاحيات المستخدم)       │        └─────────────────────────┘
 │   │ WIA / SANE                         │
 │   ▼                                    │
 │ الماسح                                 │
 └────────────────────────────────────────┘
```

- **الخادم لا يثق بالمتصفح**: كل ملف يُفحص من محتواه، والملكية تُتحقق في كل وصول.
- **الـ Agent لا يثق بالمواقع**: لا يقبل إلا أصولًا مدرجة صراحة، ويطلب جلسة اقتران مربوطة بالأصل.
- **خارج النطاق**: برمجيات خبيثة تعمل على جهاز المستخدم بصلاحياته (تستطيع قراءة إعداد الـ Agent وتزوير الطلبات المحلية؛ لا يحمي منها أي تصميم محلي).

## التهديدات والمعالجات

| التهديد | المعالجة |
|---|---|
| موقع خبيث يرسل أوامر مسح إلى الـ Agent | قائمة أصول صريحة؛ لا ترويسات CORS لغيرها؛ كل أمر يتطلب Bearer من اقتران مربوط بالأصل؛ لا اعتماد على CORS وحده. |
| DNS Rebinding (اسم نطاق يشير إلى 127.0.0.1) | فحص ترويسة `Host` على كل طلب. |
| سرقة سر الاقتران من JavaScript | السر على الخادم وفي إعداد الـ Agent فقط؛ المتصفح يتلقى توكنًا صالحًا 60 ثانية لاستخدام واحد (nonce). |
| إعادة تشغيل (Replay) للأوامر | nonce للتوكن، `requestId` فريد لكل أمر مغيّر، جلسات قصيرة (30 دقيقة متجددة، 8 ساعات حد أقصى). |
| تخمين رمز الاقتران (وضع code) | 6 أرقام، صالح دقيقتين، 5 محاولات ثم يُحرق، 10 طلبات/دقيقة. الرمز يظهر فقط في صفحة يفتحها المستخدم مباشرة (لا تُقرأ عبر fetch ولا تُضمَّن في iframe). |
| تنفيذ أوامر أو قراءة ملفات عبر الـ Agent | لا يوجد أي endpoint لذلك؛ الصور تُقرأ من مجلد المهمة المؤقت فقط بمسارات يولّدها الـ Agent؛ `deviceId` يُطابق قائمة الأجهزة. |
| استنزاف الموارد | حد للجسم (16KB)، حد معدل، مهمة واحدة لكل جهاز، حد صفحات، مهلة مسح، حذف تلقائي للمهام. |
| CSRF على Laravel | مسارات `web` مع `PreventRequestForgery` و`X-CSRF-TOKEN`. |
| IDOR | السياسات تقصر الجلسات والمستندات على المالك؛ غير المالك يتلقى 404. |
| رفع ملف ضار | فحص المحتوى (`finfo`)، بنية PDF، رفض JavaScript/Launch/EmbeddedFile/XFA/RichMedia/Encrypt، حدود الحجم والصفحات. |
| Path Traversal | مسار التخزين ULID عشوائي؛ الاسم المعروض يُنقّى؛ أصول الواجهة من قائمة ثابتة. |
| XSS | الواجهة تبني DOM بـ `textContent` فقط؛ `@json` يهرب `</script>`؛ رسائل الأخطاء نصوص. |
| تسريب معلومات | الردود لا تحوي المسار الداخلي أو القرص أو المالك؛ لا Stack Traces؛ السجلات بلا محتوى أو توكنات. |

### حدود معروفة للفحص

- `PdfInspector` لا يفك ضغط Object Streams (`/ObjStm`)؛ علامات المحتوى النشط المخبأة فيها لا تُرى. ملفات PDF التي تنشئها الواجهة لا تستخدمها. إن قبلت ملفات PDF من مصادر أخرى (`accepted_types` أو الوضع B) فأضف فحصًا أعمق (مثل `qpdf --check` أو مضاد فيروسات) في مستمع `DocumentUploaded` أو قبل التخزين.
- قيود CORS تمنع **قراءة** الردود، لا إرسال طلبات بسيطة؛ لذلك كل أمر ذي أثر يتطلب Bearer وجسم JSON (يستلزم Preflight).

## الخصوصية

1. الصور تبقى على جهاز المستخدم (ذاكرة الصفحة + مجلد مؤقت للـ Agent داخل مجلد Temp الخاص بالمستخدم (بصلاحية 0700 على Linux) يُحذف بعد الجلب) حتى يضغط «رفع».
2. تُنقل إلى الخادم فقط عبر HTTPS (في الإنتاج) ضمن جلسة مصادَق عليها، وتُخزَّن على القرص الخاص المحدد. الواجهة تعرض هذا للمستخدم قبل الرفع.
3. لا OCR ولا أي خدمة خارجية.
4. أسماء الملفات الافتراضية `scan-YYYYMMDD-HHMMSS` بلا بيانات شخصية.
5. سجل التدقيق: سجلات Laravel (معرّف الجلسة/المستند، الحجم، الصفحات، correlation id) قابلة للتعطيل عبر `logging.enabled`. جدول الجلسات يخزّن فقط إصدار الـ Agent ونوع المحوّل وعلَم المحاكي.
6. لا `localStorage` للصور.

## قائمة ما قبل الإنتاج

- [ ] HTTPS للتطبيق، `APP_DEBUG=false`، `document-scanner:check` نظيف.
- [ ] سر اقتران عشوائي (`document-scanner:secret`) يُوزَّع إلى أجهزة المستخدمين عبر قناة آمنة (أداة إدارة الأجهزة مثلًا)، وتدويره دوريًا.
- [ ] `sites` في الـ Agent تحتوي أصل الإنتاج فقط.
- [ ] `DOCUMENT_SCANNER_ALLOW_SIMULATOR=false`.
- [ ] قرص خاص؛ نسخ احتياطي وتشفير على مستوى التخزين حسب سياسة البيانات.
- [ ] حزمة Agent موقّعة ورابط تنزيل رسمي.
- [ ] جدولة `document-scanner:prune`.
- [ ] مراجعة سياسة `ScannedDocument` إن احتاج غير المالك (مشرفون) للوصول.
